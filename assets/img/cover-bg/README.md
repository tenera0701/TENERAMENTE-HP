# カバー背景画像の作り方（ChatGPT で作って置くだけ）

ブログのカバー画像は `scripts/gen-covers.js` が自動生成します。

**背景の絵柄は `scripts/cover-art.js` がその場で描くので、画像を置かなくても記事ごとに違う絵が付きます。**
slug を種にしているので、記事が違えば必ず違う配置になり、同じ記事なら何度ビルドしても同じ絵になります。
絵柄の型は5種類（`flow` / `radial` / `wave` / `grid` / `stack`）で、記事のカテゴリで選ばれます。

**このフォルダに画像を置くと、自動生成よりそちらが優先され、その絵を背景にしたカバーになります。**
自分で用意した絵に差し替えたいときだけ、以下の手順を使ってください。コードを触る必要はありません。

---

## 1. 置き方

| 置きたいもの | ファイル名 | 効く範囲 |
|---|---|---|
| その記事だけの絵 | `<slug>.jpg` 例: `2026-09-18-meo-kuchikomi.jpg` | その記事のカバー（最優先。日替わりの構図より優先されます） |
| カテゴリ共通の絵 | `meo-map.jpg` `aio-grid.jpg` `ai-wave.jpg` `app-flow.jpg` | そのカテゴリの記事すべて |

- 拡張子は **`.jpg` / `.jpeg` / `.png`**。**`.webp` は使えません**（描画エンジンが読めないため）
- ミエルームの記事は `mieroom/assets/cover-bg/<slug>.jpg` に置きます
- 置いたあと `node scripts/build-index.js`（ミエルームは `node scripts/build-mieroom.js` も）を実行
- **作り直したいときは `assets/img/covers/<slug>.png` を消してから**再ビルドしてください（既にあるカバーは作り直されません）

---

## 2. 絶対に守ること

- **画像に文字を入れない。** タイトルはビルド時に重ねます。AIが描いた日本語は崩れるので必ず「文字なし」で作ってください
- **左半分は空けて、絵柄は右側に寄せる。** 左にタイトルが乗ります
- **横長（16:9）**。仕上がりは 1200×675 前後
- 実在の企業ロゴ・人物・地図サービスの画面をそのまま写したものは使わない

---

## 3. ChatGPT に貼る指示文

### TENERAMENTE（紙白 × 黒 × 青）

共通の書き出しです。最後の【絵柄】だけ差し替えてください。

```
16:9の横長バナー用の背景画像を作ってください。

・文字は一切入れないでください（日本語も英語も禁止）
・画面の左半分は何も置かず、紙白の余白のままにしてください
・絵柄は右側の40〜45%の範囲だけに配置してください
・背景は紙のような質感のオフホワイト（#F4F2ED）
・使う色は黒（#121317）と青（#2340F5）の2色だけ。青は差し色として少量
・フラットなベクター調のミニマルな線画。写真調・3D・グラデーション・影は使わない
・細い線、点線、小さな丸や四角、矢印などの幾何学的な要素で構成する
・エディトリアルデザイン（雑誌の図版）のような落ち着いた印象に

【絵柄】ここに下から1つ
```

| カテゴリ | 【絵柄】に入れる文 |
|---|---|
| MEO | 同心円と地図ピンを中心に、周囲から矢印が集まってくる構図 |
| AIO | 細い格子の上を、点線が枝分かれしながら右上へ伸びていく構図 |
| AI | なめらかな波線が幾重にも重なり、ところどころに小さな結節点がある構図 |
| 業務アプリ | 角丸の四角形が矢印でつながれた、流れ図のような構図 |
| HP / LP | 大小の長方形を組み合わせた、ページのワイヤーフレームのような構図 |

### ミエルーム（緑 × テラコッタ）

```
16:9の横長バナー用の背景画像を作ってください。

・文字は一切入れないでください（日本語も英語も禁止）
・画面の左半分は何も置かず、余白のままにしてください
・絵柄は右側の40〜45%の範囲だけに配置してください
・背景はごく淡いミントグリーン（#F6FAF8）
・使う色は深緑（#12302B）と緑（#0F8C74）、差し色にテラコッタを少量
・フラットなベクター調のミニマルな線画。写真調・3D・強い影は使わない
・不動産仲介の店舗業務を思わせる、落ち着いた幾何学的な構図に

【絵柄】ここに下から1つ
```

| カテゴリ | 【絵柄】に入れる文 |
|---|---|
| 売上管理 | 右肩上がりの棒グラフと、それを囲む細い罫線の表 |
| 業務効率化 | 複数の線が1本に集約されていく流れ図 |
| 集客・広告 | 地図ピンと、そこへ向かう点線の経路 |
| 組織・育成 | 人型の丸と線で組まれた、ゆるやかな組織図 |
| DX | 紙の束から角丸の画面へ矢印が向かう構図 |

---

## 4. うまくいかないときは

- **絵が左まで広がってしまう** … 「左半分は完全に空白にしてください」と強めに言い直す
- **文字が入ってしまう** … 「文字・ロゴ・数字を一切描かないでください」と再指示する
- **色が派手すぎる** … 「彩度を落として、色数を2色に絞ってください」と伝える
- **縦長になる** … 「16:9の横長で」と明示する

生成した画像は `.webp` ではなく `.jpg` か `.png` で保存してください。
