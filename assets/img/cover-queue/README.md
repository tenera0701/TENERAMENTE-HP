# ChatGPT で作ったトップ画像を、毎朝のルーティンに渡す（画像の在庫）

毎朝6時のブログ自動投稿（クラウドのルーティン）は ChatGPT を使えません。
そこでトップ画像は**手元（Claude in Chrome × ChatGPT）で前もって作り、ここに「在庫」として置いておきます。**
ルーティンは、次に書くキーワードに在庫があればそれを記事のカバーに使い、無ければ従来どおりコードでカバーを作ります。

- TENERAMENTE の在庫: `assets/img/cover-queue/<キューID>.png`（1200×630）
- ミエルームの在庫: `mieroom/assets/cover-queue/<キューID>.png`（1200×675）

---

## 1. 仕組み

1. 次に書かれるキーワードを確認する
   `node scripts/seo-queue.js upcoming 3`（ミエルームは `--site=mieroom` を付ける）
2. ChatGPT で画像を作る（下の「2. ChatGPT への頼み方」）
3. 仕上げて在庫に置く
   `python scripts/place-ai-cover.py <teneramente|mieroom> <キューID> <元画像> "<記事のタイトル>"`
   - 既存のカバーと同じ寸法に切り抜く（ChatGPT は 1672×941 で返す。TENERAMENTE は上下を少し切る）
   - `<キューID>.png` で在庫に保存し、キューの項目に `coverTitle` と `coverImage` を書き込む
4. ルーティンは `coverTitle` のある項目を書くとき、**記事のタイトルを coverTitle と一字一句同じにする**
5. ルーティンが `node scripts/seo-queue.js done <id> <slug>` を実行した時点で、在庫が `covers/<slug>.png` にコピーされる
6. ビルドは `covers/<slug>.png` が既にあるので作り直さず、そのまま使う（一覧のサムネイルも OGP も同じ画像）

在庫はローカルの定期タスク「ブログのトップ画像を ChatGPT で補充」が毎日補充します。手で作るときも同じ手順です。

---

## 2. ChatGPT への頼み方（指示は1行だけ）

**細かい指示は書かない。** 配色・構図・文字の配置まで指定すると、かえって安っぽい絵になる（2026-09-18 に確認）。
ChatGPT に任せたほうが、見出し・イラスト・画面の部品までそろった絵になる。

```
ブログ用の画像を作ってほしい。内容：{記事のタイトル}
```

`{記事のタイトル}` はキューの `title`（在庫を作るとそれが `coverTitle` になる）。

### チャットはサイトごとに1つに固定する

**毎回新しいチャットを開かない。** 同じチャットで頼み続けると、絵の雰囲気がそろう。

| サイト | ChatGPT のチャット名 | 最初の依頼（HP を読み込ませ済み） |
|---|---|---|
| TENERAMENTE | 「MEO対策画像作成」 | `https://teneramente.jp/index.html` を渡して MEO の記事画像を作った |
| ミエルーム | 「申込書不備防止画像作成」 | `https://teneramente.jp/mieroom/` を渡して「HPの雰囲気を読み込んで、雰囲気を一致させて」と頼んだ |

チャットが消えたときだけ、新しいチャットを作り、最初の1通で HP を読み込ませる:

```
画像生成してほしくて。ブログのトップ画像の作成。このHP {HPのURL} の雰囲気を読み込んで、雰囲気を一致させてほしい。議題はこれ。{記事のタイトル}
```

### 入力欄のクセ（Claude in Chrome から入れるとき）

- 改行はその場で送信になる。指示文は1行で書く。
- キー入力ではなく、入力欄に `document.execCommand('insertText', false, 指示文)` で差し込む
  （日本語入力が有効な窓では、キー入力だと半角の英数字が落ちる）。差し込んだら中身を読み返してから送信する。
- 裏のタブでは画像が読み込まれない。画像を取り出す前にそのタブを表に出す（スクリーンショットを撮ると表に出る）。

## 3. できた画像の確かめ方

- **画像を拡大して、文字を全部読む。** 見出し・小見出し・チップ・画面の部品の小さな文字まで。
  誤字・脱字・崩れた文字・意味の通らない語があれば、同じチャットでもう一度同じ1行を送って作り直す。
- **描き損じ**（文字の上のにじみ・崩れた手や顔・はみ出した部品）も同じく作り直す。
- 2回だめならその項目は飛ばす（ルーティンはコード生成のカバーで記事を出すので止まらない）。
- 画面の中の例（「3位 → 12位」「★」など）は絵の一部なのでよい。見出しに実績の数字（「売上2倍」など）が入ったら作り直す。

---

## 4. 補充の目安と後片付け

- 各ブログとも、**次の3件ぶん**を在庫に持つ（3日ぶんの余裕。PC を開かない日があっても途切れない）
- 使い終わった在庫（キューが done になった項目）は消してよい。記事のカバーは `covers/` 側に残っている
- 在庫を差し替えたいときは、同じキューIDでもう一度 place-ai-cover.py を実行すれば上書きされる
- 左上が空いている絵に本物のロゴを載せたいときだけ、place-ai-cover.py に `--logo` を付ける（既定は載せない）
