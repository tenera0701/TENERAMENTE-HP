売上管理表

無料で使えます。登録なし・ネット不要。入れた内容はこの端末のブラウザの中だけに残り、どこにも送られません。

ツールを使う →

パソコンがおすすめ（印刷・CSV保存も使えます）。スマホでも動きます。

自分用に作り替えたい人へ

Claude（claude.ai）に、この文をそのまま貼って送ると、同じようなツールを作ってくれます。

お店の売上管理表のツールを、HTMLファイル1つで作って。ネット不要で動き、入れた内容はこのパソコンの中だけに保存。 ・日にちごとに、現金・カード・QR決済・電子マネーの売上と客数を入れる（あとから直す・消すもできる） ・月を選ぶと、月の合計・営業日数・客単価・1日の平均が自動で出る ・月の目標を入れたら、達成率とあといくらかも出す ・前の月より何％増えた・減ったか（月の途中なら前の月も同じ日まで） ・毎日の売上を払い方ごとのグラフで。曜日ごとの平均も ・CSV保存（Excelで文字化けしない）と印刷

作り方の細かい手順

用意するもの

  • Claude（claude.ai）にログインできるパソコン
  • ブラウザ（Chrome・Edge・Safari など）。できたツールはネット不要で動く

STEP1 Claude にこう頼む（コピペでOK）

↑ 上の「プロンプトをコピー」の文をそのまま貼る

コツ: 現金・カード・QR に分けて、と書く。書いた物しか作られない。

STEP2 Claude がツールをファイル1つ（index.html）で作る

STEP3 できたファイルを保存して、ダブルクリックで開く

ブラウザで開く。ネット不要で、入れた内容はこのパソコンのブラウザの中だけに残る。

STEP4 毎日の売上を入れる

日にち（今日が入っている）を選び、現金・カード・QR・電子マネーの売上と客数を入れて「この日の売上を入れる」。同じ日をもう一度入れると、あとの金額で上書きされる。

STEP5 月の合計・1日の平均・客単価が自動で出る

月を選ぶと、合計・営業した日数・客数・客単価が出る。目標の金額を入れると「目標の何％・あといくら」も出る。
1日の平均は、売上を入れた日（＝営業した日）で割った金額。

STEP6 グラフで一目

毎日の売上を払い方ごとに積み上げたグラフ（平均の点線・いちばん多い日と少ない日）と、曜日ごとの平均（いちばん高い曜日は濃い色）。

STEP7 前の月と比べる

「前の月と比べて」で、増えた・減ったが％で出る。今月が途中なら、前の月も同じ日までで比べる。

仕上げ

  • 毎日の一覧の行を押すと、上の欄に戻ってその日を直せる。「この日を消す」もある
  • 「CSVで保存」で Excel で開けるファイルに（最後に合計の行）。税理士さんにもそのまま渡せる
  • 「印刷する」で印刷

うまくいかないとき

  • 思った形と違う → 同じ会話で「〇〇を直して」と続けて頼めばOK（例:「PayPay の欄も足して」）
  • 別のパソコンでは、入れた内容は見えない（このパソコンのブラウザの中だけに残るため）。人に渡すときは CSV で
