サロンブログメーカー

無料で使えます。登録なし・ネット不要。入れた内容はこの端末のブラウザの中だけに残り、どこにも送られません。

ツールを使う →

パソコンがおすすめ（印刷・CSV保存も使えます）。スマホでも動きます。

自分用に作り替えたい人へ

Claude（claude.ai）に、この文をそのまま貼って送ると、同じようなツールを作ってくれます。

美容室やサロンのブログを書くツールを、HTMLファイル1つで作って。ネット不要で動き、入れた内容はこのパソコンの中だけに保存。 ・お店の名前・書く人・文の雰囲気（やわらか・元気・落ち着き）・最後に入れるひとことを、一度だけ入れる ・テーマ（新メニュー・季節のおすすめ・お手入れのコツ・スタッフ紹介・空きのお知らせ）を選び、メニューと伝えたいことを入れる ・ボタン1つで題名と本文を作る（季節のあいさつ→本題→予約の案内→ひとこと）。別の言い回しにもできる ・題名と本文はそのまま直せて、文字数も出す。コピーのボタンつき ・写真を選べて、投稿する日を決めて下書きにためておける（あとから開いて直す・消す）

作り方の細かい手順

用意するもの

  • Claude（claude.ai）にログインできるパソコン
  • ブラウザ（Chrome・Edge・Safari など）。できたツールはネット不要で動く

STEP1 Claude にこう頼む（コピペでOK）

↑ 上の「プロンプトをコピー」の文をそのまま貼る

コツ: お店の雰囲気と、テーマまで書く。書いた物しか作られない。

STEP2 Claude がツールをファイル1つ（index.html）で作る

STEP3 できたファイルを保存して、ダブルクリックで開く

ブラウザで開く。ネット不要で、入れた内容はこのパソコンのブラウザの中だけに残る。

STEP4 お店のことを一度だけ入れる

お店の名前・書く人の名前・文の雰囲気（やわらか・元気・落ち着き）・毎回最後に入れるひとこと。次からは入った状態で開く。

STEP5 テーマを選んで、伝えたいことを入れる

テーマは5つ（新メニュー・季節のおすすめ・お手入れのコツ・スタッフ紹介・空きのお知らせ）。テーマごとに欄の名前と例が変わる。伝えたいことは1行に1つ、3つくらい。

STEP6 「題名と本文を作る」を押す

季節のあいさつ（今の月から自動）→ 本題（伝えたいこと）→ 予約の案内 → ひとこと、の順で題名と本文ができる。
「別の言い回しにする」で言い回しが変わる。題名と本文はそのまま直せて、文字数も出る。

STEP7 投稿する日を決めて、下書きにためる

写真も選べる。ためた下書きは日付の順に並び、開いて直す・×で消すができる。

仕上げ

  • 「本文をコピー」「題名をコピー」で、サロンボードのブログの画面に貼るだけ
  • このツールはサロンボードに自動で投稿はしない（貼るのはお店の人）

うまくいかないとき

  • 思った形と違う → 同じ会話で「〇〇を直して」と続けて頼めばOK（例:「キャンペーンのテーマも足して」）
  • 別のパソコンでは、入れた内容は見えない（このパソコンのブラウザの中だけに残るため）
