シフト表メーカー

無料で使えます。登録なし・ネット不要。入れた内容はこの端末のブラウザの中だけに残り、どこにも送られません。

ツールを使う →

パソコンがおすすめ（印刷・CSV保存も使えます）。スマホでも動きます。

自分用に作り替えたい人へ

Claude（claude.ai）に、この文をそのまま貼って送ると、同じようなツールを作ってくれます。

お店のシフト表を自動で作るツールを、HTMLファイル1つで作って。ネット不要で動き、入れた内容はこのパソコンの中だけに保存。 ・作る月と、平日・土日に必要な人数を入れる ・スタッフごとに、出勤と退勤の時間、出られない曜日、週に何日までを入れる ・ボタン1つで1か月分を偏りなく割り振り、出勤のマスに時間を出す ・人が足りない日は赤く ・マスを押すと、その日だけ時間を直す・休みにする・出勤にするができる ・人ごとの出勤日数と合計時間も出す ・印刷（表だけ）とCSV保存（Excelで文字化けしない）

作り方の細かい手順

用意するもの

  • Claude（claude.ai）にログインできるパソコン
  • ブラウザ（Chrome・Edge・Safari など）。できたツールはネット不要で動く

STEP1 Claude にこう頼む（コピペでOK）

↑ 上の「プロンプトをコピー」の文をそのまま貼る

コツ: 出勤・退勤の時間と、出られない曜日まで書く。書いた物しか作られない。

STEP2 Claude がツールをファイル1つ（index.html）で作る

STEP3 できたファイルを保存して、ダブルクリックで開く

ブラウザで開く。ネット不要で、入れた内容はこのパソコンのブラウザの中だけに残る。

STEP4 作る月と、平日・土日に必要な人数を入れる

STEP5 スタッフの名前を足して、出勤・退勤の時間を入れる

22時〜翌2時のように日をまたぐ時間も、そのまま入れれば数えられる。

STEP6 出られない曜日を押して赤に。「週に◯日まで」も決める

STEP7 「シフトを自動で作る」を押す

その日に出られる人のうち、今月まだ出勤が少ない人から順に入り、1か月分が時間つきで完成する。週の上限は超えない。

STEP8 直したい日はマスを押す

その日だけ時間を変える・休みにする・空いたマスを出勤にする、ができる。直すたびに日数と合計時間を数え直す。

仕上げ

  • 人が足りない日は赤い行で出る（「人が足りない日が◯日あります」）
  • 「印刷する」で表だけを印刷（入力欄やボタンは出ない）
  • 「CSVで保存」で Excel で開けるファイルに（最後に出勤日数と合計時間の行）

うまくいかないとき

  • 思った形と違う → 同じ会話で「〇〇を直して」と続けて頼めばOK（例:「土日は3人にして」）
  • 別のパソコンでは、入れた内容は見えない（このパソコンのブラウザの中だけに残るため）。人に渡すときは CSV で
