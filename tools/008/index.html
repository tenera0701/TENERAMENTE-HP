名刺管理表

無料で使えます。登録なし・ネット不要。入れた内容はこの端末のブラウザの中だけに残り、どこにも送られません。

ツールを使う →

パソコンがおすすめ（印刷・CSV保存も使えます）。スマホでも動きます。

自分用に作り替えたい人へ

Claude（claude.ai）に、この文をそのまま貼って送ると、同じようなツールを作ってくれます。

名刺管理のツールを、HTMLファイル1つで作って。ネット不要で動き、入れた内容はこのパソコンの中だけに保存。 ・名刺ごとに、会社名・名前・ふりがな・部署と役職・電話・メールを入れる（あとから直す・消すもできる） ・会った日と、最後に連絡した日、どこで会ったか・どんな話をしたかのメモも残せる ・名前・ふりがな・会社名・メモの言葉で、すぐ探せる（当たった文字に色） ・しばらく連絡していない人は色を変えて「◯日 連絡なし」と出す（目安は30・60・90・180日から選べる）。「連絡した」を押すと今日に ・並べ方は、連絡していない順・会った日が新しい順・名前のあいうえお順・会社名順 ・CSV保存（Excelで文字化けしない）と印刷

作り方の細かい手順

用意するもの

  • Claude（claude.ai）にログインできるパソコン
  • ブラウザ（Chrome・Edge・Safari など）。できたツールはネット不要で動く

STEP1 Claude にこう頼む（コピペでOK）

↑ 上の「プロンプトをコピー」の文をそのまま貼る

コツ: 会った日と、話したことのメモまで書く。書いた物しか作られない。

STEP2 Claude がツールをファイル1つ（index.html）で作る

STEP3 できたファイルを保存して、ダブルクリックで開く

ブラウザで開く。ネット不要で、入れた内容はこのパソコンのブラウザの中だけに残る。

STEP4 名刺の情報を入れる

会社名・名前・ふりがな・部署と役職・電話・メールを入れて「この名刺を入れる」。ふりがなを入れておくと、ひらがなでも探せて、あいうえお順に並べられる。

STEP5 会った日とメモ

会った日（今日が入っている）と、どこで会ったか・どんな話をしたかのメモを残す。最後に連絡した日は、空のままなら会った日になる。

STEP6 名前や会社ですぐ探す

一覧の上の欄に、名前・ふりがな・会社名・メモの言葉を入れると、その名刺だけが出る（当たった文字に黄色）。カードの電話・メールを押すと、そのまま電話・メールができる。

STEP7 ご無沙汰の人に色

「ご無沙汰の目安」（30・60・90・180日）より長く連絡していない人は、カードがオレンジになり「◯日 連絡なし」と出る。上に「ご無沙汰の人 ◯人」。
連絡したらカードの「連絡した」を押すと、最後に連絡した日が今日になる。並べ方を「連絡していない順」にすると、ご無沙汰の人が上に来る。

仕上げ

  • カードの「直す」で上の欄に戻って直せる。「この名刺を消す」もある
  • 「CSVで保存」で Excel で開けるファイルに。ほかの顧客管理のツールにも移せる（探しているときは、出ている名刺だけ）
  • 「印刷する」で印刷

うまくいかないとき

  • 思った形と違う → 同じ会話で「〇〇を直して」と続けて頼めばOK（例:「住所の欄も足して」）
  • 別のパソコンでは、入れた内容は見えない（このパソコンのブラウザの中だけに残るため）。人に渡すときは CSV で
